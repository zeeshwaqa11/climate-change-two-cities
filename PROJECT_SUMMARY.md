# Project summary

Built a reproducible Python analysis of 86 years (1940 to 2025) of daily ERA5 reanalysis data for Karachi and London, using pandas, SciPy and pymannkendall to fit linear-regression and Mann-Kendall/Sen's-slope trends against a 1961-1990 climate baseline. London is warming at +0.33 °C per decade versus +0.21 °C for Karachi (both p < 0.001), London's days above its baseline 95th percentile more than doubled (18 to 40 a year in 2016-2025), and neither city shows a statistically significant rainfall trend. The project is a one-command pipeline (`run_all.py`) covering API fetching with retries, data cleaning, 80 pytest tests on synthetic data, 200-dpi publication-style figures and an executed Jupyter report. While validating the data I found that the API silently splices two models in 1950, which created a false step in the record, and corrected it before any conclusions were drawn.
